# PathForgeFever — Web-App

React + TypeScript + Vite. Marken-Konfiguration: `src/lib/brand.ts`.

## Entwicklung

```bash
npm install
npm run dev
```

Optional: `public/data/tpf2_network_export.json` ablegen, sonst Export beim Start hochladen.

## Build

```bash
npm run build
npm run preview
```
